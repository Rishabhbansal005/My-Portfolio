03

NLP · FastAPI · Python

Indian Heritage & Bharat AI

A modern, responsive redesign of the national heritage portal integrated with Bharat AI — an NLP chatbot powered by GroqCloud LLM APIs and FastAPI.

FastAPI Python GroqCloud NLP HTML/CSS
View Repository ↗ Live Demo ↗

The Indian Heritage & Culture portal existed as an older government-era design — information-dense but difficult to navigate on modern devices. The redesign rebuilt the entire UI as a responsive, accessible interface while preserving all original content, making centuries of cultural and heritage data genuinely usable.

Bharat AI's chatbot is powered by GroqCloud LLM APIs routed through FastAPI endpoints. Multi-turn context is managed server-side: on every request, the client sends its session ID, the backend retrieves the accumulated message history for that session, appends the new user message, forwards the full history to GroqCloud, then stores the assistant reply — giving the model coherent conversational memory without requiring any client-side state management.

FastAPI was chosen for its async-first design, which keeps LLM API wait times non-blocking and allows the server to remain responsive during inference calls. Session history is held in-process memory — a deliberate tradeoff that keeps the architecture simple for a demo-scale deployment at the cost of session loss on server restart, which is acceptable here.
